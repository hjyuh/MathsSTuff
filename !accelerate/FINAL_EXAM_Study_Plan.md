## PHASE 2: BUILD THE FOUNDATION (Days 2-3)

### Start with Unit 1: Foundations
This is the language of geometry. You can't do anything without it.

**Must-know checklist:**
- [ ] Distance formula — can you use it without looking it up?
- [ ] Midpoint formula — same question
- [ ] Slope formula — and what parallel/perpendicular slopes look like
- [ ] Writing equations of lines (point-slope form is your friend)
- [ ] Angle pair relationships: complementary, supplementary, vertical, linear pair
- [ ] Parallel lines + transversal: corresponding, alternate interior, alternate exterior, co-interior (same-side interior)

**How to study:** Read the Unit 1 notes. Do 5 practice problems per concept. If you get all 5 right, move on. If not, re-read and do 5 more.

### Then Unit 2: Transformations
This is the machinery that powers congruence and similarity arguments later.

**Must-know checklist:**
- [ ] Coordinate rules for translations: (x, y) → (x + a, y + b)
- [ ] Coordinate rules for reflections: over x-axis, y-axis, y = x, y = -x
- [ ] Coordinate rules for rotations: 90°, 180°, 270° (both CW and CCW)
- [ ] What rigid motions preserve (distance, angle, parallelism — everything)
- [ ] Dilations: (x, y) → (kx, ky) — NOT a rigid motion (changes size)
- [ ] Composition: applying multiple transformations in order
- [ ] Congruence = can be mapped by rigid motions

**How to study:** Make a single reference card with all the coordinate rules. Practice applying 2-3 transformation sequences to a triangle.

## PHASE 3: THE CORE — TRIANGLES & PROOFS (Days 4-6)

### Unit 3: Triangles (spend the most time here)
This is the heart of geometry.

**Must-know checklist:**
- [ ] Triangle Angle Sum = 180°
- [ ] Exterior Angle Theorem
- [ ] Triangle classification (by sides AND angles)
- [ ] ALL 5 congruence theorems: **SSS, SAS, ASA, AAS, HL**
- [ ] Why SSA does NOT prove congruence
- [ ] **CPCTC** — what it is and how to use it in proofs
- [ ] Two-column proof format: statements on the left, reasons on the right
- [ ] Isosceles Triangle Theorem (base angles are congruent)
- [ ] Midsegment Theorem
- [ ] Four triangle centers: centroid, circumcenter, incenter, orthocenter

**Proof strategy:**
1. Mark up the diagram with everything you know
2. Look for shared sides/angles (reflexive property)
3. Identify which congruence theorem applies
4. Write statements leading to the theorem
5. Conclude with CPCTC if you need a specific part

**How to study:** Do at least 5-10 proofs. There is no shortcut. You must practice writing them out.

### Unit 4: Polygons & Quadrilaterals

**Must-know checklist:**
- [ ] Interior angle sum: (n − 2) × 180°
- [ ] Each interior angle of regular polygon: (n − 2) × 180° / n
- [ ] Exterior angle sum: always 360°
- [ ] THE QUADRILATERAL HIERARCHY (this is a final exam favorite):
  - Parallelogram properties (opposite sides ∥ and ≅, opposite angles ≅, diagonals bisect each other)
  - Rectangle = parallelogram + right angles + congruent diagonals
  - Rhombus = parallelogram + all sides ≅ + ⊥ diagonals
  - Square = rectangle + rhombus
  - Trapezoid midsegment = (b₁ + b₂)/2
  - Isosceles trapezoid: base angles ≅, diagonals ≅
  - Kite: ⊥ diagonals, one pair of opposite angles ≅
- [ ] How to PROVE a quadrilateral is a specific type using coordinates (slope for ∥, distance for ≅, midpoint for bisection)

**How to study:** Make a chart comparing ALL quadrilateral types with their properties. This single chart is gold for the final.

## PHASE 4: SIMILARITY & TRIGONOMETRY (Days 7-9)

### Unit 5: Similarity

**Must-know checklist:**
- [ ] Similar = same shape, proportional sides, equal angles
- [ ] Scale factor and how to find it
- [ ] Triangle similarity theorems: **AA, SSS~, SAS~**
- [ ] Setting up and solving proportions correctly (MATCH CORRESPONDING PARTS)
- [ ] Triangle Proportionality Theorem (side-splitter)
- [ ] Ratio of perimeters = k, ratio of areas = k²
- [ ] Geometric mean in right triangles

**How to study:** Practice setting up proportions. The #1 mistake is matching the wrong sides. Always label which triangle is which.

### Unit 6: Right Triangles & Trigonometry (HIGH PRIORITY)

**Must-know checklist:**
- [ ] Pythagorean Theorem: a² + b² = c²
- [ ] Common Pythagorean triples: 3-4-5, 5-12-13, 8-15-17, 7-24-25
- [ ] **Special right triangles:**
  - 45-45-90 → sides: x, x, x√2
  - 30-60-90 → sides: x, x√3, 2x
- [ ] **SOH-CAH-TOA:**
  - sin = opposite / hypotenuse
  - cos = adjacent / hypotenuse
  - tan = opposite / adjacent
- [ ] Finding sides with trig (set up ratio, solve)
- [ ] Finding angles with inverse trig (sin⁻¹, cos⁻¹, tan⁻¹)
- [ ] Angles of elevation and depression
- [ ] Area = ½ab sin C
- [ ] **Law of Sines:** a/sin A = b/sin B = c/sin C (use for AAS, ASA)
- [ ] **Law of Cosines:** c² = a² + b² − 2ab cos C (use for SAS, SSS)

**Decision tree for triangle problems:**
```
Is it a right triangle?
├── YES → Use Pythagorean Theorem or SOH-CAH-TOA
└── NO → Do you know two angles?
    ├── YES → Use Law of Sines
    └── NO → Do you have SAS or SSS?
        └── YES → Use Law of Cosines
```

**How to study:** Do 20+ trig problems. Mix them up — some right triangle, some oblique. Practice identifying WHICH method to use.

## PHASE 5: AREA, VOLUME & CIRCLES (Days 10-12)

### Unit 7: Area, Surface Area, Volume

**Must-know checklist:**
- [ ] All 2D area formulas (rectangle, triangle, parallelogram, trapezoid, rhombus, regular polygon, circle)
- [ ] Regular polygon area: A = ½ × apothem × perimeter
- [ ] Circle: A = πr², C = 2πr
- [ ] Arc length = (θ/360) × 2πr
- [ ] Sector area = (θ/360) × πr²
- [ ] 3D Surface Area: prism, cylinder, pyramid, cone, sphere
- [ ] 3D Volume: prism (Bh), cylinder (πr²h), pyramid (⅓Bh), cone (⅓πr²h), sphere (4/3 πr³)
- [ ] Cavalieri's Principle
- [ ] Density = mass / volume
- [ ] Composite figures: break into simpler pieces

**How to study:** Make a formula sheet. Then practice WITHOUT looking at it. Time yourself — volume/area problems should be quick on a final.

### Unit 8: Circles (HIGH PRIORITY)

**Must-know checklist:**
- [ ] Central angle = intercepted arc
- [ ] **Inscribed angle = ½ intercepted arc** (this is tested CONSTANTLY)
- [ ] Inscribed angle on diameter = 90°
- [ ] Angles inside circle (two chords) = ½(arc₁ + arc₂)
- [ ] Angles outside circle = ½(far arc − near arc)
- [ ] Tangent ⊥ radius at point of tangency
- [ ] Two tangent segments from external point are ≅
- [ ] **Segment relationships:**
  - Chords: (a)(b) = (c)(d)
  - Secant-secant: (external)(whole) = (external)(whole)
  - Tangent-secant: (tangent)² = (external)(whole)
- [ ] **Equation of a circle: (x − h)² + (y − k)² = r²**
- [ ] Completing the square to convert general form → standard form
- [ ] Is a point inside, on, or outside? (Compare distance to center with radius)

**How to study:** Draw circles and label parts. Do 10+ inscribed angle problems and 10+ segment relationship problems. Practice completing the square until it's automatic.

## THE 20 MOST LIKELY FINAL EXAM QUESTION TYPES

These are the problem types that appear on almost every Honors Geometry final:

1. **Find missing angles** with parallel lines and a transversal
2. **Angle relationships** in triangles (sum = 180°, exterior angle theorem)
3. **Prove two triangles congruent** using SSS/SAS/ASA/AAS/HL
4. **CPCTC proof** — prove congruence THEN conclude a part is congruent
5. **Identify/classify a quadrilateral** given coordinates (use slope + distance)
6. **Find missing angles** in parallelograms, rectangles, rhombi
7. **Set up and solve a proportion** using similar triangles
8. **Find a missing side** using AA similarity
9. **Pythagorean Theorem** — straightforward and word problems
10. **Special right triangles** — find missing sides in 45-45-90 and 30-60-90
11. **SOH-CAH-TOA** — find a side or angle
12. **Angle of elevation/depression** word problem
13. **Law of Sines or Cosines** — solve a non-right triangle
14. **Area of a regular polygon** using apothem
15. **Volume of a composite solid** (cylinder + cone, etc.)
16. **Arc length and sector area**
17. **Inscribed angle** problems (angle = half the arc)
18. **Tangent-radius perpendicularity** and segment relationships in circles
19. **Equation of a circle** — write it, graph it, or complete the square
20. **Coordinate geometry proof** — prove a shape is a rectangle/parallelogram/etc.

## EXAM DAY STRATEGY

**Before the exam:**
- Get a good night's sleep — this matters more than one extra hour of studying
- Eat something. Your brain needs fuel.
- Bring: pencils, eraser, ruler, calculator (if allowed), and confidence

**During the exam:**
1. **First pass (15 min):** Skim the entire exam. Do every problem you immediately know how to solve.
2. **Second pass (25 min):** Go back to medium-difficulty problems. Draw diagrams. Mark up figures.
3. **Third pass (15 min):** Tackle the hardest problems. Attempt partial solutions — partial credit exists.
4. **Final check (5 min):** Review your answers. Check for silly mistakes (wrong sign, forgot √, wrong formula).

**If you're stuck:**
- Draw a picture if you don't have one
- Write down what you know (given information)
- Write down what you need to find
- Ask: "What formula or theorem connects what I know to what I need?"
- Look for hidden triangles, parallel lines, or circle relationships

**Common exam traps:**
- Forgetting to use the RADIUS (not diameter) in circle formulas
- Mixing up "congruent" (same size) and "similar" (same shape)
- Not simplifying radicals fully (leave as 5√3, not √75)
- Forgetting that inscribed angle = HALF the arc, not the full arc
- Using the wrong leg as "opposite" vs "adjacent" in trig

## YOUR FORMULA CHEAT SHEET (Memorize This)

### Coordinate Geometry
- **Distance:** d = √((x₂−x₁)² + (y₂−y₁)²)
- **Midpoint:** M = ((x₁+x₂)/2, (y₁+y₂)/2)
- **Slope:** m = (y₂−y₁)/(x₂−x₁)
- **Parallel slopes:** m₁ = m₂
- **Perpendicular slopes:** m₁ × m₂ = −1

### Triangles
- **Angle sum:** 180°
- **Exterior angle = sum of remote interior angles**
- **Pythagorean Theorem:** a² + b² = c²
- **45-45-90:** x : x : x√2
- **30-60-90:** x : x√3 : 2x
- **Area:** A = ½bh or A = ½ab sin C

### Trigonometry
- **sin = opp/hyp, cos = adj/hyp, tan = opp/adj**
- **Law of Sines:** a/sin A = b/sin B = c/sin C
- **Law of Cosines:** c² = a² + b² − 2ab cos C

### Polygons
- **Interior angle sum:** (n−2) × 180°
- **Each interior (regular):** (n−2) × 180° / n
- **Exterior angle sum:** 360°

### Quadrilaterals
- **Parallelogram:** opp sides ∥ & ≅, opp angles ≅, diagonals bisect each other
- **Trapezoid midsegment:** (b₁ + b₂) / 2

### Circles
- **Circumference:** 2πr
- **Area:** πr²
- **Arc length:** (θ/360) × 2πr
- **Sector area:** (θ/360) × πr²
- **Inscribed angle = ½ arc**
- **Equation:** (x−h)² + (y−k)² = r²

### 3D Solids
- **Prism V:** Bh
- **Cylinder V:** πr²h
- **Pyramid V:** ⅓Bh
- **Cone V:** ⅓πr²h
- **Sphere V:** (4/3)πr³
- **Sphere SA:** 4πr²
