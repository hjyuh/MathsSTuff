# EP-488 v69 A4 Pentagon Lemma: `{8,9,10,12,15}`

Date: 2026-05-18

Status: rigorous A4 subcase theorem. This does not solve A4 or EP-488.

## Theorem

Let `Z` be the ordered pure-cycle host

```text
Z_s = (8s, 10s, 15s, 9s, 12s),
```

with cycle-edge lcms

```text
40s, 30s, 45s, 36s, 24s.
```

Assume the reduced top-window pure-cycle hypotheses:

```text
15s < q < 16s,
q does not divide any of 40s,30s,45s,36s,24s,
45s <= n < 3q,
m > n.
```

Then the A4 pure-cycle inequality holds:

```text
N_Z(m)/m <= 2H_Z#(n)/n.
```

Thus every A4 pure-cycle realization of the normalized pentagon
`{8,9,10,12,15}` is harmless.

## Proof

The feasibility window gives

```text
45s <= n < 3q < 48s.
```

Therefore the raw floor values at height `n` are fixed:

```text
floor(n/8s)  = 5
floor(n/10s) = 4
floor(n/15s) = 3
floor(n/9s)  = 5
floor(n/12s) = 3
```

and

```text
floor(n/40s) = floor(n/30s) = floor(n/45s)
             = floor(n/36s) = floor(n/24s) = 1.
```

So the raw host count is

```text
5 + 4 + 3 + 5 + 3 - 5 = 15.
```

No q-excluded correction can occur in any positive vertex term. If such a
correction occurred for a vertex `ps`, put

```text
h = q/gcd(ps,q),
r = ps/gcd(ps,q).
```

Then `q/s = hp/r`, and `15 < q/s < 16`, so

```text
hp/16 < r < hp/15.
```

Also `lcm(ps,q) <= n < 48s`, so `hp < 48`. The finite table over
`p in {8,9,10,12,15}` and `2 <= h <= floor(47/p)` contains no integer `r` in
that open interval. Hence all positive q-excluded corrections vanish at
height `n`.

Negative edge q-exclusions can only increase `H_Z#(n)`, so

```text
H_Z#(n) >= 15.
```

Since `n < 48s`,

```text
2H_Z#(n)/n > 30/(48s) = 5/(8s).
```

Now bound the `m` side. Put `k = floor(m/s)`. For the positive terms,

```text
c_m(ps;q) <= floor(k/p).
```

For every edge `es`, the q-excluded edge condition gives

```text
lcm(es,q) >= 2es.
```

Therefore

```text
-c_m(es;q) <= -floor(k/e) + floor(k/(2e)).
```

Finally,

```text
c_m(360s;q) <= floor(k/360).
```

Thus

```text
N_Z(m) <= A(k),
```

where

```text
A(k) =
  floor(k/8) + floor(k/10) + floor(k/15) + floor(k/9) + floor(k/12)
 -floor(k/40) - floor(k/30) - floor(k/45) - floor(k/36) - floor(k/24)
 +floor(k/80) + floor(k/60) + floor(k/90) + floor(k/72) + floor(k/48)
 +floor(k/360).
```

Since `m > n >= 45s`, we have `k >= 45`. The function `A(k)` has period
increment

```text
A(k+720) = A(k) + 298.
```

Equivalently the average slope is

```text
298/720 = 149/360.
```

A finite check over one period, `45 <= k <= 764`, gives

```text
A(k)/k <= 149/360,
```

with equality at `k = 720`.

Therefore

```text
N_Z(m)/m <= 149/(360s).
```

Since

```text
149/360 < 5/8,
```

we conclude

```text
N_Z(m)/m <= 149/(360s) < 5/(8s) < 2H_Z#(n)/n.
```

This proves the pentagon A4 lemma.
