## Certificate

For a pure cycle `Z = (a_1,...,a_r)`, define

```text
N_Z(x) =
  sum_i c_x(a_i;q)
  - sum_i c_x(lcm(a_i,a_{i+1});q)
  + c_x(L_cyc;q).
```

The A4 pure-cycle target is

```text
N_Z(m)/m <= 2 H_Z#(n)/n.
```

After grouping coefficients by denominator `d`,

```text
N_Z(x) = sum_d alpha_d c_x(d;q),
delta = sum_d alpha_d (1/d - 1/lcm(d,q)),
E = 2 sum_d |alpha_d|,
B = 2 H_Z#(n)/n.
```

The finite certificate proves

```text
N_Z(m)/m <= delta + E/m.
```

If `eta = B - delta > 0`, only

```text
n < m <= floor(E/eta)
```

requires exact checking.

## Remaining Pure-Cycle A4 Target

The missing theorem is still uniform:

```text
For every feasible pure cycle in the ratio graph generated by
{3/2, 4/3, 5/3, 5/4}, and for every reduced realization of that cycle,
eta = 2H_Z#(n)/n - delta is positive and the resulting finite window has no
A4 violation.
```

The tested data suggests a possible stronger margin statement:

```text
eta/B >= 3400409/7056784
```

for the canonical realizations through length 16, but this is only evidence.
It is not yet a theorem and should not be used as a ledger assumption.
