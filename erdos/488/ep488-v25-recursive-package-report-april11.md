# EP-488 v25 — Recursive Package Diagnostics (Codex run)
## April 11, 2026

This note records the *actual* recursive package coefficients `P_s` generated by the v25 recurrence

`P_s = C*(s) + Σ_{(s→t,h) live} (h/2)·P_t`

using:

- the corrected universal `t`-bound from convexity: `t = floor((s+1)·λ) <= 10·(s+1)`,
- `C*(s) = max_{s < t <= 10·(s+1)} ((s+1)L_s(t) - 2t)`,
- band badness ranges `U_s` built from the exact coefficient
  `c_s(λ) = (s+1)(L_s(floor((s+1)λ)) - 2λ)`,
- **live edges** = geometric edges `(h/2)I_s ∩ I_t != ∅` with `U_s ∩ U_t != ∅`,
  where `I_s = (n/(s+1), n/s]`.

All computations are exact rational arithmetic.

Code: `erdos/488/ep488_recursive_package_v25.py`

## 2) Outgoing live-edge count is NOT O(1)

The live out-degree grows with `s` under the v25 “live edge” definition.

Computed out-degree samples:

- `outdeg(50)=10`
- `outdeg(100)=22`
- `outdeg(150)=34`
- `outdeg(200)=42`
- `max outdeg(s<=500)=114` (at `s=472`)

So the conjecture “each band has only `O(1)` live outgoing edges” is **false** at least in the
literal digraph `(s→t,h)` sense used by the recurrence.

## 3) Exact lambda-sum at λ = 29/20 up to s = 200

At `λ = 29/20` the number of active bands `s ∈ [4,200]` (excluding `5`) is:

- `194` active bands (matches the earlier coexistence observation)

But the exact v25 package-weighted sum is enormous:

`Σ_{active s<=200} c_s(29/20) · P_s · (2s+1)/(s^2 (s+1)^2)  ≈ 57462.4115`

So this sum is **not** `< λ` (it is >> `1.45`).

## 4) Structural reason the summability route fails (as currently stated)

Two compounding effects appear in the computed model:

1. **Out-degree growth:** many live edges per band; once multiple `h` values appear to small bands,
   the recurrence begins to accumulate a harmonic-type contribution.
2. **Large exact coefficients at λ = 29/20:** for most `s <= 200`, `c_s(λ)` is already positive and
   typically grows with `s` (roughly like `~ s^2/log s` once `t < s^2`).

Even if `P_s` were `O(s^2)`, the per-band term behaves like `~ const/s`, producing logarithmic growth.
With the observed `P_s/s^2` drift upward, the partial sums blow up quickly.
