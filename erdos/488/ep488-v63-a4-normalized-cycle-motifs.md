# EP-488 v63 A4 Normalized Cycle Motifs

Date: 2026-05-18

Status: partial A4 progress and correction to the v62 motif outlook. This is
not a proof of A4 or EP-488.

## Purpose

v62 checked pure cycle hosts through `q <= 500` and found 13 normalized motifs.
v63 replaces raw `q`-scanning with a normalized edge-ratio model.

The main lesson is:

```text
The q<=500 motif list is not a complete pure-cycle motif list.
```

There is still a finite local edge alphabet, but normalized cycle motifs keep
appearing beyond `q=500`.

## Edge-Ratio Alphabet

Let `a,b in (q/2,q)` and suppose

```text
L = lcm(a,b) <= n < 3q.
```

Write

```text
a = d u,
b = d v,
gcd(u,v)=1,
u < v.
```

Since `a,b > q/2` and `uvd = L < 3q`, while `q < 2du`, we get

```text
v < 6.
```

Together with `u < v < 2u`, the only possible reduced edge types are:

```text
2:3, 3:4, 3:5, 4:5.
```

This is a genuine structural reduction for pure cycles.

## Script

```powershell
python .\ep488_v63_a4_normalized_cycle_motifs.py --max-len 12 --json-out ep488_v63_a4_normalized_cycle_motifs_len12.json

python .\ep488_v63_a4_normalized_cycle_motifs.py --max-len 14 --json-out ep488_v63_a4_normalized_cycle_motifs_len14.json
```

The script:

1. Builds the rational graph generated by edge ratios
   `{3/2,4/3,5/3,5/4}` inside a top-window interval.
2. Enumerates simple cycles containing the normalized minimum.
3. Clears denominators to get normalized integer motifs.
4. Filters by the real top-window feasibility condition:

```text
max(max_vertex, max_cycle_edge_lcm/3) < 2 min_vertex.
```

5. Constructs one concrete `(q,n,cycle)` realization for each motif.
6. Checks the A4 pure-cycle host margin for that realization.

## Corrected Remaining A4 Target

The remaining A4 theorem should now be stated as an infinite normalized
edge-ratio theorem, not a fixed finite motif table:

```text
Pure-Cycle Ratio Theorem:
For every simple cycle in the ratio graph generated by
{3/2, 4/3, 5/3, 5/4} satisfying the top-window feasibility inequality, every
reduced realization satisfies

2m H_Z#(n) - n H_Z#(m) >= n c_m(L_cyc(Z))

at every relevant event point m.
```

This is plausibly more tractable than raw A4 because the edge alphabet is only
four types, but it is not yet proved.
