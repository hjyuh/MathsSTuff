# EP-488 v66 A4 Realization-Window Sweep

Date: 2026-05-18

Status: partial A4 progress. This does not prove A4 or EP-488.

## Purpose

v65 certified one canonical realization for every normalized pure-cycle motif
through length 16. That was not enough for a uniform A4 theorem, because a
fixed normalized cycle can have many admissible `(scale,q,n)` realizations.

v66 probes those realization windows directly.

## Script

```powershell
python .\ep488_v66_a4_realization_window.py
```

For each selected normalized pure-cycle motif, the script:

1. varies the scale;
2. samples admissible `q` values in the top-window interval;
3. samples dangerous `n` values, namely endpoints just before jumps of
   `H_Z#(n)`;
4. computes the finite-certificate margin
   `eta = 2H_Z#(n)/n - delta`;
5. exactly finite-certifies the weakest sampled rows.

This is still a sampler, not a proof.

## Exact Triangle Barrier Family

The realization sweep exposes a clean infinite family.

For every `s >= 1`, set

```text
Z_s = {12s,15s,20s}
q_s = 24s - 1
n_s = 72s - 4 = 3q_s - 1
m_s = 108s.
```

Then the top-window constraints hold:

```text
20s < q_s < 24s = 2 min(Z_s),
5q_s/2 <= n_s < 3q_s,
lcm(12s,15s) = lcm(15s,20s) = lcm(20s,12s) = 60s <= n_s.
```

For these points, the q-excluded corrections do not affect the displayed
counts, and

```text
H_Z#(n_s)
 = floor((72s-4)/(12s))
 + floor((72s-4)/(15s))
 + floor((72s-4)/(20s))
 - 3 floor((72s-4)/(60s))
 = 5 + 4 + 3 - 3
 = 9.
```

Also

```text
N_Z(m_s)
 = floor(108s/(12s))
 + floor(108s/(15s))
 + floor(108s/(20s))
 - 2 floor(108s/(60s))
 = 9 + 7 + 5 - 2
 = 19.
```

Therefore the ratio to the A4 bound is exactly

```text
(N_Z(m_s)/m_s) / (2H_Z#(n_s)/n_s)
 = (19/(108s)) / (18/(72s-4))
 = (342s - 19)/(486s)
 = 19/27 - 19/(486s).
```

Thus pure-cycle A4 has an infinite family approaching

```text
19/27 ~= 0.7037037037
```

of the available bound. This is harmless for A4, but it is now the observed
extremal target. Any proof strategy that only studies canonical realizations
misses this barrier.

## Corrected A4 Target

The pure-cycle theorem should be sharpened to:

```text
For every feasible normalized cycle in the ratio graph generated by
{3/2,4/3,5/3,5/4}, every admissible realization satisfies
N_Z(m)/m <= 2H_Z#(n)/n for all m > n.
```

The triangle subproblem should probably be separated:

```text
Triangle A4 Lemma:
For every realization of the normalized cycle {12,15,20}, the A4 inequality
holds for all m > n. The extremal family is expected to be
q = 24s-1, n = 3q-1, m = 108s, with limiting ratio 19/27.
```

After that, the remaining pure-cycle theorem can focus on cycles of length
at least 5, where the sampled margins are much lower.
