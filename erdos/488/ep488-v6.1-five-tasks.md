# EP-488 (v6.1): Five Tasks — Results
## April 5, 2026

Working from paper v6.1 with Conjecture 10.1: `ratio(A) ≤ 1 - 1/max(A)`.

## TASK 1: ELEMENT-ADDITION CONJECTURE — **FALSE**

**Claim:** Adding an element c to primitive A keeps the ratio the same or decreases it.

**Test:** 163,725 (A, c) pairs across k=2..7, max ≤ 50.

**Result:** **61,582 violations (37.61% rate).** The conjecture fails frequently.

### Worst violations

| A | c | ratio(A) | ratio(A∪{c}) | Excess |
|---|---|----------|--------------|--------|
| {6,8,14,15,21} | 10 | 0.5952 | 0.6653 | +0.0700 |
| {4,6,7,9,11,13} | 5 | 0.5883 | 0.6558 | +0.0675 |
| {8,10,14,15,19,21} | 6 | 0.5873 | 0.6548 | +0.0675 |

**Consequence:** The "pairs are worst" argument via element addition is dead. Adding an element can make the ratio WORSE — specifically when the new element creates a "dead zone" structure with the existing set.

**Why:** Adding a small element between min(A) and the cluster fills in the dead zone and raises min G, but also creates new local maxima that push max G up relatively more. The net effect is ratio increase.

## TASK 4: IS 2G(M) > S₁ FOR ALL PRIMITIVE SETS?

**Result:** **YES**, verified for 116,021 sets (k=2..7, max ≤ 50). Zero failures.

But this is **NOT sufficient for EP-488**: 2G(M) > S₁ only handles n = M. We need 2·min(G over [M,∞)) > G(m) for all n ≥ M.

### The stronger check: **2·min G > S₁**

**Result for k ≤ 9, max ≤ 40:** HOLDS (0/139,459 failures).

**But FAILS for large k:**
- **First 21 primes** {2,3,...,73}: 2·min G = 1.694, S₁ = 1.757, deficit 0.062
- **2·{first 21 primes}** {4,6,...,146}: 2·min G = 0.847, S₁ = 0.878, deficit 0.032

For these sets, **max G ≪ S₁** (e.g., 0.987 vs 1.757 for the 21 primes), so the ratio still stays below 1 even though 2·min G < S₁.

### Refined bound: 2·min G > min(S₁, 1)

For large k, max G < 1 (since 1 ∈ [1,m] is never a multiple of any element ≥ 2).

**Test:** 2·min G > min(S₁, 1)?
- k ≤ 9, max ≤ 40: 0/226,273 failures ✓
- **But fails for 2·{first 21 primes}**: 2·min G = 0.847 < min(0.878, 1) = 0.878

**Neither S₁ nor 1 is the right upper bound on max G for all cases.**

## TASK 5: AT WHAT n DOES 2G(n) FIRST EXCEED S₁?

**Result:** Max n/M across all tested sets = **1.000**, at adjacent pair (2, 3).

For sets in the k ≤ 7 range: 2G(n) > S₁ at n = M exactly (or immediately after). So the "sparse-mass-like" inequality kicks in right at max(A). This is the mechanism behind the Task 4 success for small k.

**But for large k sets where the sparse-mass inequality fails globally** (like 21 primes), 2G(n) > S₁ NEVER holds for any n ≥ M. The proof must use max G < 1 instead.

## TASK 3: DIRECT PROOF FOR k ≥ 3 — THE RIGHT BOUND

The attempted bound `max G ≤ 1 - 1/M` FAILS:
- {2, 3}: max G = 3/4 > 2/3 = 1 - 1/M

The trivial bound `G(m) ≤ 1 - 1/m` HOLDS at each m (since F(m) ≤ m-1), but the RHS depends on m, not on fixed M.

For the 21-prime set: max G = 0.98718 at x = 78, and 1 - 1/78 = 0.98718 exactly. **The bound max G ≤ 1 - 1/max_g_x is TIGHT**.

The attempted bound `2·min G > 1 - 1/M` FAILS massively (203,044/226,273 failures = 89.7%).

**Conclusion:** There is no simple universal lower bound on min G that exceeds max G. The ratio bound must be about the RATIO directly, not individual terms.

## THE CORRECT CLAIM (Conjecture 10.1 in paper v6.1)

**For every primitive set A:** `ratio(A) = max G / (2·min G) ≤ 1 - 1/max(A)`.

**Evidence:**
- Verified for 800,000+ primitive sets, 0 violations.
- Adjacent pairs {M-1, M} asymptotically achieve equality.
- Depends only on max(A).
- Immediately implies EP-488 (ratio < 1).

**Why previous attempts failed:**
1. `ratio(A) ≤ ratio({a, a+1, ..., a+k-1})` (min-monotonicity): **false** (50K+ violations).
2. `ratio(A) ≤ ratio(A ∪ {c})` (element addition): **false** (37% violations).
3. `2·min G > S₁`: **false** for large k (21 primes).
4. `2·min G > 1 - 1/M`: **false** (89% violations).
5. `max G ≤ 1 - 1/M`: **false** for small sets ({2, 3}).

**Only the ratio-based bound survives.** This means the proof must work with the COMBINED quantity max G / min G, not the individual parts.

## STRUCTURAL OBSERVATIONS

### The two regimes

**Regime A: Small k / sparse.** max G is close to S₁. min G is close to 1/a. The sparse-mass argument works: `2/a > S₁`.

**Regime B: Large k / dense.** max G is close to 1 (since G approaches δ which can be close to 1). min G is close to δ. The `2G > 1` argument works.

**The transition** happens around `S₁ = 1` / `δ = 1/2`. In this transition zone, neither bound is clean. But the ratio `max G / (2 min G)` stays bounded below 1.

### Why max G can be close to 1 - 1/max_g_x

At the point x* where max G is achieved, F(x*) is close to x* (nearly all integers below x* are hit). The only integer guaranteed NOT to be hit is 1. So F(x*) ≤ x* - 1, giving G(x*) ≤ 1 - 1/x*. This bound is tight for very dense sets at small x*.

### Why min G stays bounded above S₁/2 for small k

For small k, the multiples of each element spread out enough that min G doesn't dip too far below δ. Specifically, min G ≥ F(M)/M ≥ k/M (from the elements themselves) plus contributions from multiples of min(A).

## PATH FORWARD

The ratio bound `ratio ≤ 1 - 1/max(A)` is the cleanest universal statement. Proving it requires handling:

1. **Adjacent pairs** (proved): exact formula gives `1 - 1/M + O(1/M²)`.
2. **Non-pairs**: show `ratio(A) < ratio({M-1, M})` for all primitive A with max = M and |A| ≥ 3.

The second step is a **max-monotonicity** statement: the adjacent pair with the same max is the worst case. Unlike min-monotonicity (false), max-monotonicity is empirically supported:

- All 800K+ tested sets have ratio ≤ ratio({M-1, M}) with same M.
- Adjacent pairs always achieve the supremum for their max.

**The proof sketch:** For A with |A| ≥ 3 and max(A) = M:
- F_A(M) ≥ F_{M-1,M}(M) = 2 (both M-1 and M counted) + extra contributions from other elements.
- So G_A(M) ≥ 2/M + (extra).
- And max G_A might be smaller than max G_{M-1,M} due to more uniform coverage.
- Net: ratio(A) < ratio({M-1, M}).

Making this rigorous is the remaining challenge.
