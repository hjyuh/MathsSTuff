# EP273

Researched: 2026-04-26

Canonical page: https://www.erdosproblems.com/273

Status: open.

Tags: number theory, covering systems.

## Statement

Does there exist a covering system whose moduli are all of the form
`p-1`, where `p` is prime and `p >= 5`?

## Current Notes

The official page records that Selfridge found an example using divisors
of `360` if the prime `p = 3` is allowed. The open problem is the stricter
version where every modulus must come from `p-1` for a prime at least `5`.

The statement is formalized in Lean according to the Erdos Problems
database.
