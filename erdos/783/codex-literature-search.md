CONTEXT:
EP-783 asks: given a pairwise coprime set A ⊆ {2,...,N} with sum 1/n ≤ C, what choice of A minimizes the number of integers m ≤ N not divisible by any a ∈ A?

Current state:
- Erdős conjectured consecutive primes are extremal
- Chojecki proved this for C ≤ log 2
- Tao identified the weak form: the minimum is (ρ(e^C) + o(1))N where ρ is Dickman's function
- Hildebrand (1987, Acta Arithmetica XLVIII, "Quantitative mean value theorems for nonneg multiplicative functions II") proved the weak form WHEN A consists only of primes
- The gap: extending from prime sets to general pairwise coprime sets
