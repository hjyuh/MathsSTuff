## 1.2 Spike set on dyadic units
For `q = 2^m`, the half-density survivor ratio set is exactly
\[
\mathcal S_q = \{u \in (\mathbb Z/q\mathbb Z)^\times : u \equiv 3 \pmod 4\}.
\]

Equivalently,
\[
\mathcal S_q = \{x : \chi_4(x) = -1\},
\qquad
\chi_4(u)=(-1)^{(u-1)/2}.
\]

And equivalently,
\[
\{x:\chi_4(x)=-1\}
=
\left\{1+\frac{2}{u},\ 1-\frac{2}{u} : u \equiv 1 \pmod 4\right\}.
\]

This is the exact algebraic description of the spike survivors.

## 1.4 Mixed-shift exact formula
For a block construction with block size `q`, total length `Mq`, and shift `b=tq+r`, the gain decomposes exactly into `P/Q` contributions.

For a library of words `W_λ` and block labels `σ`, define:
- `P_r(W)` from the non-wrap part,
- `Q_r(W)` from the wrap part,
- kernel costs
  \[
  K_r^P(\lambda,\mu)=|P_r(W_\lambda)\setminus S(W_\mu)|,
  \qquad
  K_r^Q(\lambda,\mu)=|Q_r(W_\lambda)\setminus S(W_\mu)|.
  \]

Then mixed gain is
\[
G(tq+r)=\sum_{j=t}^{M-1} K_r^P(\sigma_{j-t},\sigma_j)
+
\sum_{j=t+1}^{M-1} K_r^Q(\sigma_{j-t-1},\sigma_j).
\]

This is the exact finite object behind the mixed-shift obstruction program.

# 3. Dyck correction bridge

## 3.1 A5.1 Dyck correction theorem
For any half-density word `W` with prefix defect
\[
H(W)=\max_k (-S(k))_+,
\]
there exists a Dyck half-density word `W^#` with
\[
|W^\# \triangle W| \le 2H(W).
\]

This was proved rigorously using:
- record-minimum flips,
- then last-crossing flips,
- while preserving prefix nonnegativity.

## 3.2 Kernel stability
If words are changed by `m` positions, local mixed costs change by at most linear error in `m`.

Hence:
- if `H(W)=o(q)`,
- then Dyck correction perturbs all mixed kernels by `o(q)`.

This is a crucial bridge:
- we can now design **pre-Dyck** half-density words algebraically/probabilistically,
- then Dyck-correct them safely.
