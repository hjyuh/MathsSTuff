# EP675 lane 6: dense prime partitions

Problem page: https://www.erdosproblems.com/675

Thread: https://www.erdosproblems.com/forum/thread/675

## Question

Let the primes be partitioned as

```text
Primes = P sqcup Q,
```

with both parts dense in the weak sense

```text
pi_P(x), pi_Q(x) >> x/log x
```

for all sufficiently large `x`. Define

```text
A = S(P) = {n >= 1 : every prime divisor of n lies in P}.
```

Equivalently, `A` is the multiplicative semigroup generated by `P`, with
`1 in A`. The question is whether this `A` can have the translation property:
for every `n`, there is `t >= 1` such that

```text
a in A  iff  a+t in A      for all 1 <= a <= n.
```

The official page records that Brun's sieve proves the translation property
for avoidance sets with pairwise coprime forbidden moduli `B` when

```text
sum_{b < x, b in B} 1/b = o(log log x).
```

Here the forbidden moduli would be the primes in `Q`, so for a dense `Q` the
sum is comparable to `log log x`, not `o(log log x)`. Thus the quoted Brun
criterion does not settle the dense-prime-partition case.

## First reduction: only the allowed initial segment matters

For `n >= 1`, put

```text
Q_n = {q in Q : q <= n},
M_n = product_{q in Q_n} q,
F_n = A cap [1,n].
```

### Lemma

If there exists an integer `s >= 1` such that

```text
M_n s + a in A       for every a in F_n,
```

then `t = M_n s` is a translation witness for `[1,n]`.

### Proof

If `a in F_n`, the required conclusion `a+t in A` is exactly the hypothesis.

If `1 <= b <= n` and `b notin A`, then some prime `q in Q` divides `b`.
Since `q <= b <= n`, we have `q | M_n`. Hence

```text
b + M_n s == b == 0 mod q,
```

so `b+M_n s` has a prime divisor from `Q`, and therefore is not in `A`.

This proves the lemma.

### Consequence

The nonmember side is easy. By forcing `t` to be divisible by all forbidden
primes up to `n`, every initial nonmember automatically remains a nonmember
after translation. The hard part is only:

> Can the finite allowed pattern `F_n` be shifted by a multiple of `M_n` back
> into the multiplicative semigroup `S(P)`?

Equivalently, for every `n`, do the linear forms

```text
L_a(s) = M_n s + a,       a in F_n,
```

simultaneously take values in `S(P)` for some integer `s`?

This is the clean formulation of the dense prime partition subproblem.

## CRT/local obstruction audit

There is no immediate finite CRT obstruction.

Fix `n`, and consider the tuple

```text
L_a(s) = M_n s + a,       a in F_n.
```

For a forbidden prime `q in Q`:

1. If `q <= n`, then `q | M_n`, and

   ```text
   L_a(s) == a mod q.
   ```

   Since `a in A`, no prime from `Q` divides `a`; in particular `a not== 0 mod q`.
   Thus no small forbidden prime `q <= n` can ever divide any `L_a(s)`.

2. If `q > n`, then `q` does not divide `M_n`, and the bad classes are

   ```text
   s == -a M_n^{-1} mod q,       a in F_n.
   ```

   Since `|F_n| <= n < q`, these bad classes cannot cover all residues modulo
   `q`.

Therefore, for every finite set of forbidden primes, CRT leaves at least one
class of `s` avoiding all forbidden divisibilities. Any obstruction must be
global/sieve-theoretic, not a local congruence obstruction.

This is a useful contrast with some covering-congruence problems: the dense
partition condition by itself does not create an obvious modular impossibility.

## Sieve heuristic

For fixed `n`, let

```text
m = |F_n|.
```

If `Q` behaves regularly with reciprocal density `delta_Q`, a random `s <= X`
should have roughly

```text
Prob(L_a(s) is Q-free for all a in F_n)
    about C_n (log X)^(-delta_Q m),
```

after the harmless local factors at primes `q <= n` are removed. Thus the
expected count up to `X` is of size

```text
X / (log X)^(delta_Q m),
```

which tends to infinity for each fixed `n`.

This suggests the following:

- For random or sufficiently equidistributed dense partitions, the translation
  property should plausibly hold.
- For arbitrary adversarial dense partitions, density alone may be too weak for
  a direct lower-bound sieve, because the problem asks for simultaneous values
  of many linear forms inside a sparse multiplicative semigroup.

The key point is that `n` is fixed while choosing `t_n`; the number of forms
`m=|F_n|` may be large, but it is still fixed during the sieve step.

## Conditional positive theorem

The reduction above gives an immediate abstract criterion.

### Proposition

Let `P sqcup Q` be any prime partition, and let `A = S(P)`. Suppose that for
every `n`, with `M_n` and `F_n` as above, there is an integer `s >= 1` such
that

```text
M_n s + a in S(P)       for every a in F_n.
```

Then `A` has the translation property.

This is just the lemma restated, but it isolates the only remaining input.

### Stronger but reusable sufficient hypothesis

It is enough to assume the following finite-pattern recurrence property:

For every finite `F subset S(P)` and every integer `M` with

```text
gcd(M, product_{a in F} a) = 1
```

and with no local obstruction modulo primes in `Q`, there exists `s` such that

```text
M s + a in S(P)       for all a in F.
```

Then `S(P)` has the translation property.

For EP675 we only need this with

```text
F = F_n,       M = M_n.
```

This is probably the right interface with existing multiplicative-set or
sieve-in-linear-forms technology.

## What stronger assumptions would likely be enough?

The weak density hypothesis

```text
pi_P(x), pi_Q(x) >> x/log x
```

does not include distribution in arithmetic progressions or interval
regularity. For a clean first theorem, we should strengthen the partition
hypothesis.

Plausible sufficient assumptions:

1. **Reciprocal density with uniform AP distribution.**

   Assume `P` has Dirichlet/reciprocal density `delta_P > 0`, and primes in `P`
   satisfy a prime-number-theorem-in-AP type estimate uniformly over every
   fixed modulus. This should imply good distribution of the semigroup `S(P)`
   in fixed residue classes.

2. **Linear-forms lower bound for `S(P)`.**

   Assume that for every fixed admissible tuple of affine-linear forms
   `L_1,...,L_m`, one has

   ```text
   #{s <= X : L_i(s) in S(P) for every i}
       >>_{L_1,...,L_m} X / (log X)^C
   ```

   for some finite `C`. Then EP675 follows immediately for that partition.
   This is tautological as a theorem input, but it is a precise target.

3. **Random prime partition.**

   If each prime is placed in `P` independently with probability
   `alpha in (0,1)`, the heuristic above predicts the translation property
   almost surely. A rigorous proof would likely use second-moment estimates for
   multiplicative weights such as

   ```text
   alpha^{omega(L_1(s) ... L_m(s))}
   ```

   over fixed linear forms. This looks more approachable than the worst-case
   dense partition.

4. **Block-regular partitions.**

   If every sufficiently long logarithmic prime interval contains fixed
   positive proportions of both `P` and `Q`, then the semigroup `S(P)` should
   have enough mass in every large scale to support the finite-pattern
   recurrence. This might be the most natural deterministic strengthening.

## Why dense arbitrary partitions may be hard

The lower-density assumption alone allows adversarial behavior:

- `P` and `Q` can be arranged in long blocks while still satisfying
  `pi_P(x), pi_Q(x) >> x/log x`.
- The semigroup `S(P)` can have irregular distribution in residue classes and
  intervals, even if its global counting function is large.
- The finite-pattern condition requires many correlated values
  `M_n s + a` to lie in `S(P)` simultaneously.

Thus I would not expect the full arbitrary-dense case to fall from elementary
CRT alone. The CRT audit says there is no local obstruction; it does not give
the global recurrence.

## Possible negative direction

A counterexample partition would need to make `S(P)` fail the finite-pattern
recurrence above. Since no finite local obstruction exists for the specific
forms `M_n s+a`, the obstruction would probably be one of:

1. **Long-scale gaps:** arrange `P` in blocks so that `S(P)` has long intervals
   or arithmetic progressions avoiding all required shifted patterns.

2. **Residue irregularity:** arrange `P` so that `S(P)` is badly distributed
   in certain residue classes modulo large moduli tied to `M_n`.

3. **Correlation obstruction:** arrange `P` so that individual forms
   `M_n s+a` often hit `S(P)`, but the whole tuple almost never does.

None of these is immediate from density alone. This is why the dense partition
question looks genuinely harder than the squarefree-growth subproblem.

## Next concrete tasks

1. **Write the reduction as a polished lemma.**

   This should go into any EP675 note: it is short and removes half the
   translation constraints.

2. **Search literature for multiplicative semigroups generated by prime sets.**

   Relevant phrases:

   - multiplicative sets generated by primes of positive density;
   - Wirsing theorem multiplicative sets arithmetic progressions;
   - values of linear forms in multiplicative sets;
   - sifted values of linear forms with positive-dimensional allowed primes.

3. **Prove a regular-partition theorem.**

   Target statement:

   > If `P` has reciprocal density `delta_P > 0` and the semigroup `S(P)` obeys
   > a fixed-linear-forms lower-bound sieve, then `S(P)` has the translation
   > property.

   This is likely reachable and would be a useful partial result.

4. **Random model.**

   Try to prove that an independent random prime partition with parameter
   `alpha in (0,1)` almost surely has the translation property. Even a proof
   for one fixed `n` with summable failure probabilities after choosing huge
   search ranges `X_n` would be informative.

5. **Adversarial construction attempt.**

   Try block partitions of primes and test whether `S(P)` fails the
   recurrence condition for small `n`. This can be light computation, not SAT:
   just dynamic programming over reachable residues and interval scales.

## Lane verdict

The dense-prime-partition question does not collapse immediately, but the
right reduction is now clear:

```text
translation property for S(P)
    <= finite-pattern recurrence of S(P) along forms M_n s + a.
```

There is no finite CRT obstruction. Regular/random dense partitions should
plausibly satisfy the property. Arbitrary dense partitions remain risky because
global distribution of the semigroup `S(P)` is uncontrolled by density alone.

For full EP675, this lane is probably a serious subproblem, not the easiest
closure path. For a publishable partial, a regular-partition theorem or a
random-partition theorem looks realistic.
