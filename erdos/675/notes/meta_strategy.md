# EP675 Meta Strategy

Lane 8 role: coordinate the EP675 paths, separate full-solve prospects from
publishable partials, and identify the next theorem worth proving after the
squarefree audit.

Sources checked:

- Official page/thread: https://www.erdosproblems.com/forum/thread/675
- Squarefree comment: Ho Boon Suan claims `t_n > exp(n^c)` for every
  `c < 25/72`, using Nunes' least-squarefree-in-AP bound.
- Nunes dependency: least squarefree integer in a reduced residue class
  `L(q,r) <= C_eps q^(36/25 + eps)`.

## 1. Problem decomposition

EP675 is really three related problems.

1. Sums of two squares.
   Let `B_2` be the set of integers representable as a sum of two squares.
   Does `B_2` have the translation property?

2. Dense prime partitions.
   Given a partition of primes `P sqcup Q` with both parts dense in the
   prime-counting sense, does the multiplicative semigroup generated by `P`
   have the translation property?

3. Squarefree growth.
   For the squarefree set, the translation property is known by elementary
   sieve theory. The quantitative question is how quickly the least preserving
   shift `t_n` must grow.

The squarefree question is the best immediate audit target. The sums-of-two-
squares question is the headline target. The prime-partition question is the
least structured and probably needs additional hypotheses before it becomes
tractable.

## 2. Full-solve prospects

### Squarefree quantitative growth

Current status: likely close to a publishable partial, not a full asymptotic.

The claimed comment route is:

```text
If t preserves squarefreeness on [1,n] and p^2 does not divide t,
find a squarefree a <= n with a == -t mod p^2.
Then a+t is divisible by p^2, contradiction.
```

Nunes' bound gives this for `p <= n^c`, `c < 25/72`, hence

```text
t_n >= prod_{p <= n^c} p^2 = exp((2c+o(1)) n^c).
```

Best use: turn this into a clean general theorem.

```text
Theorem template.
Assume that for all reduced residue classes r mod q,
there is a squarefree m == r mod q with m <= C_eps q^(theta+eps).
Then every squarefree-preserving shift on [1,n] satisfies
t_n > exp(n^c) for all c < 1/(2 theta).
```

With `theta=36/25`, this gives `c<25/72`.

Full asymptotic growth remains open. A full answer would need an upper bound
construction for small shifts or a sharper forced-divisibility mechanism.

Estimated status:

- positive-power lower bound: 75-85% once audited carefully;
- full squarefree growth law: 25-35%;
- useful note/post: very plausible.

### Sums of two squares

Membership in `B_2` is controlled by primes `q == 3 mod 4`: every such prime
must occur to even valuation. This makes the problem p-adic rather than merely
squarefree.

The full translation-property question is hard because for every `a <= n` with
`a in B_2`, one must arrange `a+t in B_2` simultaneously. Since

```text
|B_2 cap [1,n]| ~ C n / sqrt(log n),
```

the positive positions alone impose many conditions. A naive random shift is
not expected to work without serious sieve structure.

However, lower bounds on any possible preserving shift look much more
accessible. This is the strongest next theorem after the squarefree audit.

### Dense prime partitions

If `A_P` is the set of integers all of whose prime factors lie in `P`, then
for each small `q in Q`, a preserving shift should be forced to be highly
divisible by powers of `q`, provided one can find small `P`-smooth integers in
specified residue classes mod powers of `q`.

That last distribution input is not automatic for arbitrary dense partitions.
This lane should be postponed until we have a robust p-adic theorem for
structured multiplicative sets.

Estimated full-solve prospects:

- sums of two squares: 10-15% initially;
- prime partition question: 10-20%, highly dependent on extra distribution
  input;
- meaningful p-adic lower-bound partials: 45-60%.

## 3. Single strongest next theorem

After the squarefree audit, prove the following sums-of-two-squares forced
divisibility theorem.

### Target theorem: forced `3 mod 4` divisibility

Let `B_2` be the set of sums of two squares. Suppose `t` preserves `B_2` on
`[1,n]`, i.e.

```text
a in B_2  iff  a+t in B_2      for all 1 <= a <= n.
```

Then for every prime `q == 3 mod 4` in a fixed power range

```text
q <= n^c
```

one has at least

```text
q | t
```

and, with a more careful induction on `v_q(t)`, one should be able to force

```text
v_q(t) >= floor(log_q n) - O_L(1)
```

for all `q <= n^c`, where `L` is an admissible Linnik-type exponent for primes
in arithmetic progressions.

This would imply a lower bound of the shape

```text
t >= exp(n^c)
```

for every sufficiently small absolute `c>0`.

This does not solve the translation-property existence question for `B_2`, but
it is a strong, relevant theorem about any possible shifts. It also establishes
the correct local obstruction language for the full problem.

## 4. Proof sketch for the next theorem

The basic contradiction step is elementary.

Take a prime `q == 3 mod 4`.

If `q` does not divide `t`, choose a small prime `ell` such that

```text
ell == 1 mod 4,
ell == -t + q mod q^2.
```

Then `ell` is a sum of two squares, but

```text
ell + t == q mod q^2,
```

so `v_q(ell+t)=1`, and `ell+t` is not a sum of two squares. If
`ell <= n`, this contradicts preservation on `[1,n]`.

By Linnik's theorem applied to modulus `4q^2`, such an `ell` exists with

```text
ell << q^(2L+eps).
```

Thus `q | t` for all `q <= n^(1/(2L)-eps)`.

For higher powers, write `s=v_q(t)`.

- If `s` is even, choose `a=q^s b` with `b` a small sum of two squares and
  `b == -t/q^s + q mod q^2`. Then `a in B_2`, but `a+t` has odd
  `q`-adic valuation.
- If `s` is odd, choose `a=q^(s+1)b` with `b in B_2` small and coprime to
  `q`. Then `a in B_2`, but `a+t` still has odd `q`-adic valuation `s`.

The size of `a` grows like a fixed power of `q` times `q^s`. This should force
`s` up to `log_q n - O(1)` for all sufficiently small `q`.

Dependencies:

- Linnik for primes in AP is enough for a weak positive exponent.
- Any stronger least-prime-in-AP result improves the exponent.
- No heavy computation is needed.

## 5. Dependency graph

```text
Squarefree audit
  -> general least-squarefree-AP implication
  -> clean partial note for EP675 squarefree growth

Sums-of-two-squares lower bound
  -> Linnik/AP prime input
  -> forced q-adic divisibility for q == 3 mod 4
  -> exp(n^c) lower bound for any preserving shift

Full B_2 translation property
  -> need constructive sieve/recurrence theorem
  -> must handle all a <= n with a in B_2 simultaneously
  -> currently the main hard barrier

Prime partition question
  -> requires distribution of P-smooth/P-supported numbers in APs
  -> probably follows only under stronger assumptions on the partition
```

## 6. Action plan

1. Finish the squarefree audit.
   Check the non-reduced residue issue, the exponent conversion, and the
   product lower bound. Write a self-contained theorem using a parameter
   `theta`.

2. Prove the first-level `B_2` divisibility lemma.
   Show that if `t` preserves sums of two squares on `[1,n]`, then
   `q | t` for all primes `q == 3 mod 4`, `q <= n^c`, with explicit `c`
   from Linnik.

3. Upgrade to the valuation induction.
   Force `v_q(t)` large enough to get a product lower bound
   `t >= exp(n^c)`.

4. Only then revisit existence for sums of two squares.
   The forced divisibility theorem will reveal how large the CRT modulus must
   be, which is essential before designing a constructive sieve.

## 7. Posting standard

The squarefree lower-bound theorem is postable if:

- the exact Nunes theorem is cited correctly;
- the residue-class reduction is fully checked;
- all constants are quantified as `for every c < 25/72`;
- the proof is written independently, not just paraphrased from the comment.

The `B_2` forced-divisibility theorem is postable as a partial result if it
gives any explicit positive exponent. It does not need to prove translation
property existence to be meaningful.
