Goal: isolate concrete algebraic operations that might turn a known
\(K_{r,s}\) factor-difference witness into a larger biclique.  The operations
below are not claimed to solve EP885.  They are stated so that each can be
tested or killed by exact arithmetic.

## 1. Working model

A \(K_{r,s}\) witness consists of distinct positive row differences

\[
d_1,\ldots,d_r
\]

and distinct positive column values

\[
N_1,\ldots,N_s
\]

such that, for every \(i,j\),

\[
N_j=a_{ij}(a_{ij}+d_i)
\]

for some integer \(a_{ij}\ge 1\).  Equivalently,

\[
y_{ij}^2=d_i^2+4N_j,\qquad y_{ij}=2a_{ij}+d_i.
\]

Put \(x_j=4N_j\).  A row extension asks for a new \(d\) with

\[
d^2+x_j=\square\qquad (1\le j\le s),
\]

and a column extension asks for a new \(x=4N\) with

\[
d_i^2+x=\square\qquad (1\le i\le r).
\]

Rational data are enough.  If \(d_i,N_j,y_{ij}\in\mathbb Q\) satisfy

\[
y_{ij}^2=d_i^2+4N_j,
\]

then choosing \(L\) to be twice a common denominator gives an integer witness

\[
(Ly_{ij})^2=(Ld_i)^2+4(L^2N_j),
\]

with integral factor lower term

\[
a'_{ij}=\frac{L(y_{ij}-d_i)}2.
\]

Thus a lift may be designed over \(\mathbb Q\), with positivity and
distinctness checked after clearing denominators.

## 3. Identity bank

### 3.1 Square scaling

If \(d\in D(N)\), then

\[
qd\in D(q^2N)
\]

because

\[
N=a(a+d)\quad\Longrightarrow\quad
q^2N=(qa)(qa+qd).
\]

For a whole witness,

\[
(d_i,N_j)\mapsto (qd_i,q^2N_j)
\]

preserves the same \(K_{r,s}\).  It is not an enlarging operation by itself,
but it is essential for clearing denominators and aligning separate rational
constructions.

### 3.2 Product gaps

Suppose

\[
N=a(a+d),\qquad M=c(c+e).
\]

Then \(NM\) has the two product factor pairs

\[
ac,\quad (a+d)(c+e),
\]

and

\[
a(c+e),\quad c(a+d).
\]

Therefore

\[
a e+c d+d e\in D(NM),
\]

and

\[
|a e-c d|\in D(NM).
\]

The case \(e=0\), \(M=q^2\), recovers square scaling.

### 3.3 Two-row factorization

For two even target differences \(2\alpha,2\beta\), columns are generated by
factorizations of

\[
C=\alpha^2-\beta^2.
\]

If

\[
UV=C,
\]

then

\[
X=\frac{U+V}{2},\qquad Y=\frac{V-U}{2}
\]

satisfy

\[
X^2-\alpha^2=Y^2-\beta^2.
\]

Thus

\[
N=X^2-\alpha^2
\]

has both differences \(2\alpha\) and \(2\beta\), after clearing denominators
if \(U,V\) are rational.  This is the algebra behind the
Erdos-Rosenfeld \(k=2\) mechanism.  It gives many columns for two rows, but
does not explain how to add a third row.

### 3.4 Three-row elliptic parametrization

For fixed rows \(d_1,d_2,d_3\), put

\[
A=d_1^2-d_2^2,\qquad B=d_1^2-d_3^2.
\]

A column \(x=4N\) is the same as a value \(\lambda\) for which

\[
\lambda,\quad \lambda-A,\quad \lambda-B
\]

are all squares.  These square triples are controlled by

\[
E(A,B):\quad W^2=X(X-A)(X-B).
\]

The Jimenez-Urroz construction uses positive-rank elliptic curves of this
shape and denominator clearing to produce many columns for three fixed rows.
For lifting, this is a column-generation operation:

\[
K_{3,s}\leadsto K_{3,s+1},K_{3,s+2},\ldots
\]

provided the generated columns also pass any extra row conditions.

### 3.5 Two-column row elliptic curve

For fixed shifts \(x_1,x_2\), put \(C=x_2-x_1\).  A row \(d\) satisfies

\[
d^2+x_1=y_1^2,\qquad d^2+x_2=y_2^2.
\]

Parametrize the conic \(y_2^2-y_1^2=C\) by

\[
p=y_2-y_1,\qquad
y_1=\frac{C-p^2}{2p},\qquad
y_2=\frac{C+p^2}{2p}.
\]

Then \(d\) must satisfy the quartic

\[
(2pd)^2=(C-p^2)^2-4x_1p^2.
\]

Generically this is an elliptic curve.  Existing rows give rational points on
it.  The row-lift test is: use the group law on this curve to generate new
rational \(d\)'s, then keep only those that also satisfy the remaining
columns.

### 3.6 Rational divisor-grid form

The square-shift condition is equivalent to a rational divisor grid.  Define

\[
R_{ij}=y_{ij}+d_i,\qquad S_{ij}=y_{ij}-d_i.
\]

Then

\[
R_{ij}S_{ij}=x_j,\qquad R_{ij}-S_{ij}=2d_i.
\]

Thus a rational \(K_{r,s}\) is exactly a matrix of rational factor pairs whose
products are column-constant and whose differences are row-constant.

A concrete low-rank ansatz is

\[
R_{ij}=u_i v_j,\qquad
S_{ij}=\frac{x_j}{u_i v_j},
\]

with equations

\[
u_i v_j-\frac{x_j}{u_i v_j}=2d_i.
\]

This is not automatically solvable, but it gives a small algebraic system to
test against known seeds.  If a seed can be transformed into such a rank-one
or rank-two divisor grid, then appending a row or column may reduce to a
low-dimensional rational parametrization rather than a new high-genus solve.

## 4. Candidate lifting operations

### Operation A: common square scaling plus rational specialization

Input: a rational parametric grid

\[
y_{ij}(t)^2=d_i(t)^2+4N_j(t).
\]

Action:

1. Choose rational parameters avoiding poles and equalities.
2. Clear denominators with one even multiplier \(L\).
3. Output rows \(Ld_i(t)\) and columns \(L^2N_j(t)\).

This operation enlarges a witness only if the rational family already has
more rows or columns.  Its role is to make rational parametrizations usable
for integer EP885 data.

### Operation B: elliptic row lift from two columns

Input: a \(K_{r,s}\) with \(s\ge 2\).

Action:

1. Select two columns \(x_a,x_b\).
2. Build the two-column elliptic curve from Section 3.5.
3. Use the known \(r\) rows as rational points.
4. Generate candidate new rows by elliptic addition.
5. Keep a generated row \(d_{\mathrm{new}}\) only if

\[
d_{\mathrm{new}}^2+x_j=\square
\]

for every remaining column \(j\).

Success signal: a new row gives \(K_{r+1,s}\).  Then a column-extension step
can try to produce \(K_{r+1,s+1}\).

Main risk: once \(s\ge 3\), the extra square conditions are generically
genus \(5\) or higher.

### Operation C: elliptic column lift from three rows

Input: a \(K_{r,s}\) with \(r\ge 3\).

Action:

1. Select three rows \(d_a,d_b,d_c\).
2. Form \(E(A,B)\) as in Section 3.4.
3. Use existing columns as rational points when possible.
4. Generate candidate new columns by elliptic addition.
5. Keep a generated column \(x_{\mathrm{new}}\) only if

\[
d_i^2+x_{\mathrm{new}}=\square
\]

for every remaining row \(i\).

Success signal: a new column gives \(K_{r,s+1}\).

Main risk: checking the fourth and fifth row is a high-genus filter unless
the chosen rows lie in a special family.

### Operation D: twisted product multiplier

Input: a witness \(N_j=a_{ij}(a_{ij}+d_i)\).

Choose a multiplier for each column,

\[
M_j=c_j(c_j+e_j),
\]

and form

\[
N'_j=N_jM_j.
\]

For a fixed source row \(d_i\), the product identities give candidate gaps

\[
g_j^+=a_{ij}e_j+c_jd_i+d_ie_j,
\]

and

\[
g_j^-=|a_{ij}e_j-c_jd_i|.
\]

If the \(c_j,e_j\) can be chosen so that \(g_j^+=g\) or \(g_j^-=g\) is
independent of \(j\), then \(g\) is a common row for the new columns
\(N'_j\).

To obtain several rows at once, each same \(M_j\) must have several selected
factor pairs

\[
c_{hj}(c_{hj}+e_{hj})=M_j
\]

whose product gaps collapse to target common differences \(g_h\).  This is
the most concrete product-lift system:

\[
g_h=a_{\sigma(h),j}e_{hj}+c_{hj}d_{\sigma(h)}
       +d_{\sigma(h)}e_{hj}
\]

or

\[
g_h=\left|a_{\sigma(h),j}e_{hj}
       -c_{hj}d_{\sigma(h)}\right|,
\]

for all selected columns \(j\).  The unknowns are the column multipliers
\(M_j\), their selected factor pairs, the row map \(\sigma\), and the target
gaps \(g_h\).

This operation is worth testing because it avoids asking directly for a new
point on a fixed high-genus curve.  It replaces that problem by structured
factor-pair matching.

### Operation E: fixed common multiplier obstruction

A simpler product idea is to multiply every column by the same \(M=c(c+e)\)
and use the same factor pair \(c,c+e\) for every column.  For one source row
\(d_i\), the new product gaps are

\[
a_{ij}e+cd_i+d_ie
\]

and

\[
|a_{ij}e-cd_i|.
\]

Unless \(e=0\) or the lower factors \(a_{ij}\) are all equal across columns,
these vary with \(j\).  Thus fixed non-square multiplication does not
normally add a common row.  Any successful product lift must use either:

- pure square scaling;
- column-dependent multipliers;
- different factor pairs of the same multiplier;
- or a special witness where the \(a_{ij}\)'s satisfy a collapse relation.

This obstruction should be used to kill naive product claims quickly.

### Operation F: tensor or diagonal product of two witnesses

Suppose a first witness has data \(N_j=a_{ij}(a_{ij}+d_i)\) and a second
witness has data

\[
M_\ell=c_{u\ell}(c_{u\ell}+\epsilon_u).
\]

The product columns \(P_{j\ell}=N_jM_\ell\) have mixed gaps

\[
G^+_{i,u,j,\ell}
=a_{ij}\epsilon_u+c_{u\ell}d_i+d_i\epsilon_u,
\]

and

\[
G^-_{i,u,j,\ell}
=|a_{ij}\epsilon_u-c_{u\ell}d_i|.
\]

A diagonal product lift chooses a subset of product columns

\[
P_j=N_jM_{\pi(j)}
\]

and asks whether \(G^+_{i,u,j,\pi(j)}\) or
\(G^-_{i,u,j,\pi(j)}\) is independent of \(j\).  The minus mode requires an
affine matching

\[
a_{ij}\epsilon_u-c_{u,\pi(j)}d_i=\pm g,
\]

and the plus mode requires

\[
a_{ij}\epsilon_u+c_{u,\pi(j)}d_i=g-d_i\epsilon_u.
\]

So tensoring is not a free construction; it succeeds only when lower-factor
tables from two witnesses have matching affine patterns.  This is still
testable on \(K_{4,3}\), Guiduli-style \(K_{4,3}\) seeds, and future Bremner
\(K_{4,4}\) data.

### Operation G: alternating row-column lift

This is the direct induction template:

\[
K_{r,r}\to K_{r+1,r}\to K_{r+1,r+1}.
\]

Step 1 is Operation B or D.  Step 2 is Operation C or a product analogue.
The key point is closure: after adding the row, the enlarged object must
remain in a family where adding a column is still controlled.  An isolated
row extension is not enough for an all-\(k\) proof.

## 5. Genus obstructions

### Fixed rows, variable column

For fixed distinct rows \(d_1,\ldots,d_r\), columns \(x=4N\) lie on

\[
y_i^2=x+d_i^2,\qquad 1\le i\le r.
\]

Generically, for \(r\ge 3\), the genus is

\[
g=1+(r-3)2^{r-2}.
\]

Thus:

\[
\begin{array}{c|ccccc}
r & 1 & 2 & 3 & 4 & 5\\
\hline
g & 0 & 0 & 1 & 5 & 17
\end{array}
\]

The \(r=3\) case is elliptic and supports the Jimenez-Urroz mechanism.  The
\(r=4,5\) cases are already high genus unless the rows are special.

### Fixed columns, variable row

For fixed shifts \(x_1,\ldots,x_s\), rows \(d\) lie on

\[
y_j^2=d^2+x_j,\qquad 1\le j\le s.
\]

Generically, for \(s\ge 2\), the genus is

\[
g=1+(s-2)2^{s-1}.
\]

Thus:

\[
\begin{array}{c|ccccc}
s & 1 & 2 & 3 & 4 & 5\\
\hline
g & 0 & 1 & 5 & 17 & 49
\end{array}
\]

This explains why a \(K_{4,3}\to K_{5,3}\) row extension is already a
genus \(5\) filter after choosing the three columns, and why a direct
\(K_{5,5}\) search is unlikely to reveal a repeatable proof without extra
structure.

### Practical use of genus

The genus obstruction should prune proposed operations, not discourage the
problem itself.  A viable all-\(k\) construction must do at least one of the
following:

- vary the curves with \(k\) so the needed points are forced;
- keep the problem on rational or elliptic quotients;
- make the high-genus curve split or cover a lower-genus curve;
- manufacture finitely many required points by product identities instead of
  finding them on a fixed generic curve.

If a proposed lift adds a square condition and reduces to

\[
v^2=P(u)
\]

with squarefree \(\deg P\ge 5\), then it needs a visible reason for its
points.  Otherwise it is probably an isolated high-genus accident.

## 6. Falsifiable lemmas and computational tests

The following are intended as exact-arithmetic tests.  They do not require
editing existing scripts.

### Test 1: fixed-multiplier product collapse

Claim to test/prove: Let \(N_j=a_j(a_j+d)\) be one row of a witness with at
least two distinct \(a_j\)'s.  Fix one factor pair \(M=c(c+e)\).  If either

\[
a_je+cd+de
\]

or

\[
|a_je-cd|
\]

is independent of \(j\), then \(e=0\).

Why it matters: if true, multiplying all columns by one non-square factor
cannot add a row.  Product lifts must be twisted or tensorial.

Failure condition: find a known witness row and one fixed \(M\) with \(e>0\)
whose product gap is constant over all selected columns.

### Test 2: twisted product lift on the forum seed

Input: the \(K_{4,3}\) seed in Section 2.

Bounded search problem: for each source row \(d_i\), signs
\(\sigma_j\in\{\pm1\}\), and target \(g\), solve

\[
c_jd_i-a_{ij}e_j=\sigma_j g,\qquad M_j=c_j(c_j+e_j),
\]

with \(c_j,e_j>0\).  Then ask whether the same three multipliers \(M_j\)
also admit factor pairs producing four or five target gaps.

Success condition: produce new columns \(N'_j=N_jM_j\) with at least five
common differences, or at least a \(K_{5,3}\).

Failure condition: under a stated bound on \(g,e_j,c_j,M_j\), no nontrivial
solution exists beyond square scaling.

### Test 3: two-column elliptic row lift from the forum seed

Input: any pair among

\[
316800,\quad 908820,\quad 5034240.
\]

Build the quartic

\[
w^2=(C-p^2)^2-4x_1p^2,\qquad C=x_2-x_1.
\]

The known four rows give rational points.  Compute sums and differences of
these points on the associated elliptic curve, recover candidate \(d\)'s, and
test whether

\[
d^2+316800,\quad d^2+908820,\quad d^2+5034240
\]

are all squares.

Success condition: a new positive \(d\notin\{36,468,692,1028\}\), giving a
\(K_{5,3}\).

Failure condition: the subgroup generated by the known points, up to a
specified height, gives no new row passing the third column.

### Test 4: three-row elliptic column lift from the forum seed

Input: any three rows among

\[
36,\quad 468,\quad 692,\quad 1028.
\]

Form

\[
E(A,B): W^2=X(X-A)(X-B).
\]

Use the three known columns as rational square triples.  Generate new
candidate columns by elliptic addition and keep only those passing the fourth
row.

Success condition: a new \(N\notin\{79200,227205,1258560\}\), giving a
\(K_{4,4}\).  Repeating after that would be the first plausible path toward
\(K_{5,5}\).

Failure condition: generated points up to a stated height either duplicate
known columns or fail the fourth row.

### Test 5: divisor-grid rank test

For a witness, form

\[
R_{ij}=y_{ij}+d_i,\qquad S_{ij}=y_{ij}-d_i.
\]

Test whether, after multiplying rows and columns by rational square factors
or reordering rows/columns, the \(R\)-matrix has rank \(1\) or low rank, or
whether ratios

\[
\frac{R_{ij}R_{i'j'}}{R_{ij'}R_{i'j}}
\]

belong to a small finite set.

Success condition: the forum seed, Guiduli seeds, or a Bremner \(K_{4,4}\)
falls into a low-rank rational divisor-grid family.  Then append operations
can be attempted inside that family.

Failure condition: all known seeds have generic rank/ratio behavior, making
the simple divisor-grid ansatz unlikely.

### Test 6: diagonal tensor product collapse

Input: two witnesses with lower-factor matrices \(a_{ij}\) and \(c_{u\ell}\).

For every row pair \((i,u)\), search for a matching \(\pi\) and a constant
\(g\) such that

\[
a_{ij}\epsilon_u-c_{u,\pi(j)}d_i=\pm g
\]

or

\[
a_{ij}\epsilon_u+c_{u,\pi(j)}d_i=g-d_i\epsilon_u
\]

for every selected \(j\).

Success condition: a product-column set with a new common row.

Failure condition: no affine matching exists for any pair of known seeds
under all permutations of the smaller column set.

### Test 7: local square obstruction filter

For candidate shifts \(x_1,\ldots,x_s\), test small primes \(p\).  If

\[
\{d\bmod p: d^2+x_j \text{ is a square mod }p\text{ for all }j\}
\]

is empty for some \(p\), then no integer row can be added.

Dually, for candidate rows \(d_1,\ldots,d_r\), if

\[
\{x\bmod p: x+d_i^2 \text{ is a square mod }p\text{ for all }i\}
\]

is empty for some \(p\), then no integer column can be added.

Success condition: proposed product or elliptic lifts survive all small-prime
filters.

Failure condition: a small prime eliminates the family before expensive
search.

### Test 8: genus escalation certificate

For each one-parameter row or column lift, eliminate auxiliary variables until
the final extra square condition has the form

\[
v^2=P(u).
\]

Compute the squarefree degree of \(P\) and the genus.  If the genus is
\(>1\), look for an explicit quotient, splitting, or forced finite set of
points.

Success condition: the family has a rational or elliptic quotient explaining
the required points.

Failure condition: the family produces a generic high-genus curve with no
local points or no visible forced points.

## 7. Recommended next algebraic workflow

1. Extract Bremner's \(K_{4,4}\) data in the same
   \((d_i,N_j,a_{ij},y_{ij})\) format as Section 2.
2. Run Tests 1, 5, and 6 on the forum seed, Guiduli seeds, and Bremner seed.
   These are structural and should be cheap.
3. Run Test 3 on the three two-column pairs of the forum seed.  This is the
   cleanest row-extension route to \(K_{5,3}\).
4. Run Test 4 on the four three-row subsets of the forum seed.  This is the
   cleanest column-extension route to \(K_{4,4}\).
5. Only after a row or column lift is found, attempt the alternating
   \(K_{r,s}\to K_{r+1,s}\to K_{r+1,s+1}\) induction.

The strongest positive signal would be the same operation working on both
the forum \(K_{4,3}\) and Bremner's \(K_{4,4}\).  The strongest negative
signal would be that every attempted lift reduces to an unrelated high-genus
curve with no quotient and no local points.
